# Request Lifecycle

## Statuses
Not validated yet: you submitted the request and it is waiting for an admin to check it.
Validated: the admin checked your request and it waits for an officer.
Officer assigned: an officer has been given your request.
Pending: the officer is working on it now.
Task done: your request is completed.

## Priorities
Low, Medium and High tell officers how urgent a request is. Please choose High only when it is really urgent.

## Editing
You can edit your request only while it is still "not validated yet". After that, add a comment instead.

## Comments and remarks
You can add remarks when you submit the request and comments at any time. Admin and officers reply in the comments.
